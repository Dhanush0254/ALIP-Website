# ALIP — Adaptive Learning Intelligence Platform

B.Tech Final Year Project | TKR College of Engineering | CSE 2023–2027

## Stack
React 18 · Vite · Tailwind CSS v3 · Framer Motion · React Router v6

## Run locally
npm install
npm run dev

## Deploy to GitHub Pages
npm run deploy

## Project
AI-powered adaptive learning OS for B.Tech students.
Personalized by timetable, past results, and learning behavior.
Powered by RAG, local NLP models, Groq API, and Gemini.
